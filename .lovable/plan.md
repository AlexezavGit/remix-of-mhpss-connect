# План перебудови

Запит великий — розбиваю на 6 блоків. Виконуватиму послідовно, з візуальною перевіркою після кожного.

## 1. Полагодити навігаційне кільце (пріоритет)

Зараз кільце виглядає як технічні позначки і зменшилось. Треба повернути **трьохрядну топографічну шкалу**:

- Ряд 1 — глобальна навігація (5 пунктів + логотип + мова/тема)
- Ряд 2 — локальна навігація по відкритій сторінці (якорі)
- Ряд 3 — тікер з mini-bars, великими значеннями, ▲/▼, джерелом
- Правильні пропорції, читабельні розміри, як на попередньому скріні `Screenshot_2026-07-07_at_17.09.31.png`

## 2. Прибрати "смужки градієнта"

На скрінах видно вертикальні лінії/розриви на фонових градієнтах (`--gradient-hero`, помаранчево-зелені банди) і різкі стики між секціями градієнту, яких не повинно бути. Замінити на єдиний плавний градієнтний фон на всій сторінці.

## 3. Уніфікувати логотипи партнерів

На `/consortium` логотипи різних розмірів, більшість на білому. Зробити:

- Однакова висота логотипа (напр., 40px) та однакова ширина підкладенки білого кольору, як під тими логотипами що є
- Спільна світла плашка з м'яким padding для всіх
- `object-fit: contain`, центрування

**Переносимо на "Вхід" (яка стане "Користувачам"):**

## 5. Нова сторінка "Користувачам" (`/login` → `/users`)

Це швидкий вхід до кабінетів + пояснення шляху. Головний артефакт — **квест-мапа з паралельними треками (наведено скорочену, потрібно розширити на всі стержні)**:

```text
    Бенефіціар          Виконавець           Донор
        │                    │                  │
    [перший контакт]    [онбординг]      [створення програми]
        │                    │                  │
    [бот-триаж] ──▶──  [circulation folder]  ──▶── [ескроу]
        │                    │                  │
    [1-й сеанс] ──▶── [цифрове рукопожаття] ──▶── [списання]
        │             (start/stop + GPS +           │
        │              feedback + AI)               │
    [триаж 2]              │              [ESG/CSR звіт]
        │              [запис у історію]           │
    [курс 5 / 12-20 / 28д]  │                     │
```

Стержні (вертикальні шини знизу питання які фільтрують аудиторії на відповідні сторінки):

- Депереоніфікований реєстр
- Проекти (створюють виконавці, доступні донорам)
- Програми фінансування (створюють донори)
- Єдиний датасет
- Ескроу
- Автоматична звітність
- Клінічні шкали / feedback
- Тригер-система за протоколом

**Горизонтальні "тригерні" питання** в кінці кожного треку:

- "Запустити діагностичний тест / AI-розмову?" → мікросайт шлях отримувача допомоги (покроково що буде відбуватись +`Golden Scenario: Beneficiary Journey/users/beneficiary)` з формою Sign In
- "Запустити онбординг для фахівців?" → мікросайт шлях надавача допомоги (покроково що буде відбуватись)`/users/provider` з Sign In
- "Запустити протокол програми фінансування?" → мікросайт шлях (покроково що буде відбуватись +`Scoring Matrix` смарт-контракту +`Reverse Waterfall`) `/users/donor` з Sign In

Три мікросторінки успадковують поточну Sign In форму (розділяємо її на 3 варіанти).
